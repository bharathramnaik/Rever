# EPIC-010: Knowledge Graph

## Status
Pending (Phase 5)

## Stories

### STORY-010.1: Graph visualization
- Interactive force-directed graph
- Zoomable, pannable
- Node status colors (learned, learning, not started, mastered)
- Tap nodes for details

### STORY-010.2: Relationship management
- Display concept relationships (prerequisite, related, etc.)
- Navigation between related concepts
- "Why does this matter" chain
- Prerequisite unlock logic

### STORY-010.3: Mastery heatmap
- Color-coded knowledge graph
- Filter by topic/difficulty
- Progress indicators per node
- "Knowledge gaps" identification

### STORY-010.4: Learner profile visualization
- Topic mastery radar chart
- Strongest/weakest topics
- Learning style breakdown
- Shareable knowledge profile

## Acceptance Criteria
- [ ] Knowledge graph renders with correct relationships
- [ ] Node colors reflect mastery level
- [ ] Users can navigate from graph to concept
- [ ] Learner profile is shareable
