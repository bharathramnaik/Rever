# EPIC-007: Learning Paths & Progress

## Status
Pending (Phase 2)

## Stories

### STORY-007.1: Learning path engine
- Create/define learning paths
- Path contains ordered steps (learning objects)
- Prerequisite tracking between concepts
- Progress per path

### STORY-007.2: Progress dashboard
- Mastery % per topic
- Concepts learned count
- Time spent tracking
- Weekly/monthly activity charts
- Quiz performance stats

### STORY-007.3: Spaced repetition
- SM-2 algorithm implementation
- Review scheduling
- Due review notifications
- Review session UI (flashcard mode)

### STORY-007.4: Learning history
- Timeline view of all sessions
- Filter by topic/type
- Search past sessions
- Export learning history

## Acceptance Criteria
- [ ] Users can follow a learning path step by step
- [ ] Progress dashboard shows accurate statistics
- [ ] Spaced repetition schedules reviews correctly
- [ ] Learning history is searchable and filterable
