# Design System

## Brand

- Name: Rever
- Tagline: Your Personal Learning OS
- Voice: Warm, intelligent, encouraging

## Colors (Adult)

| Token | Light | Dark | Usage |
|-------|-------|------|-------|
| `primary` | #6C63FF | #8B83FF | Brand, CTAs |
| `secondary` | #00D9A6 | #00E6B3 | Success, progress |
| `surface` | #FFFFFF | #1A1A2E | Cards, backgrounds |
| `background` | #F5F5FA | #12121E | Page backgrounds |
| `text` | #1A1A2E | #E8E8F0 | Body content |
| `textSecondary` | #6B6B80 | #9E9EB0 | Subtle text |
| `accent1` | #FF6B6B | #FF6B6B | Alerts, streaks |
| `accent2` | #FFD93D | #FFD93D | Highlights |

## Colors (Kids)

Brighter, more saturated palette with playful accents.
Same structure but warm tones and larger contrast ratios.

## Component Primitives

- `ReverButton` — Primary, Secondary, Ghost, Icon
- `ReverCard` — Learning card with image + title + preview
- `ConceptCard` — Full concept view with swipeable sections
- `ProgressBar` — Streak, mastery, daily goal
- `AvatarComponent` — Profile avatar with optional badge
- `TopicChip` — Selectable topic filter
- `QuizCard` — Multiple choice question
- `FlashcardFront / FlashcardBack`
- `LessonCard` — For daily journey items
- `AIBubble` — Chat message from AI tutor
