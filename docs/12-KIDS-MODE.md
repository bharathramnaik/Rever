# Kids Mode

## Experience Design

Kids mode is NOT a button on the adult app — it's a separate presentation engine sharing the same platform.

### Age Bands

| Age | Experience |
|-----|------------|
| 5-7 | Stories + images + narration |
| 8-10 | Animations + simple concepts + activities |
| 11-13 | Interactive explanations + quizzes |
| 14-17 | Deeper explanations + projects + AI tutor |

### Kids Content Flow

```
Story / Hook
   ↓
Animation / Visual
   ↓
Simple explanation
   ↓
Interactive activity
   ↓
Question
   ↓
Reward (XP + Badge)
   ↓
Next adventure
```

### Gamification (Kids)

- XP points for learning
- Badges for milestones
- Levels with unlockable content
- Characters / avatars
- Learning worlds (topic-based)
- Daily missions
- Streak rewards

### Parent Controls
- Age level setting
- Daily learning duration limit
- Topic restrictions
- AI availability toggle
- Content restrictions
- Notification preferences
- Progress reports
- Learning goals
- Parent PIN protection

## AI Safety (Kids)

- Bounded AI interactions (predefined question types)
- Age-appropriate response templates
- No unrestricted chat
- Content filtering
- No personal data collection
- All interactions logged for parent review
