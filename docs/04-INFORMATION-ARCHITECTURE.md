# Information Architecture

## Navigation Structure (Adult)

```
Bottom Nav
├── Home (Daily Journey, Continue Learning, Your Knowledge)
├── Explore (Topics, Search, Trending)
├── Library (Saved, Notes, History, Spaces)
├── AI Tutor (Conversation, Suggested Questions)
└── Profile (Settings, Achievements, Account)

Drawer / Menu
├── Your Knowledge Map
├── Learning Paths
├── Achievements
└── Help & Support
```

## Navigation Structure (Kids)

```
Home
├── Today's Adventure
├── Your Worlds (Topics)
├── Rewards (Badges, XP)
└── Profile (Avatar, Settings)
```

## Content Hierarchy

```

    │   │           ├── Quiz

    │   └── Relationships
    ├── Library
    │   └── Saved Objects
    ├── Learning Spaces

```

## Search → Learn

Traditional search is replaced with:
```
✨ What do you want to learn?

User: "Blockchain"

Response:
├── Quick answer (2 min)
├── Visual explanation (5 min)
├── Beginner lesson (10 min)
├── Interactive map
├── Full learning path
└── Ask AI
```
