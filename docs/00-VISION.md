# Rever — Personal Learning OS

## Vision

An AI-powered personal learning environment that transforms trusted public knowledge into short, visual, interactive and personalized learning experiences for adults and children.

## Core Philosophy

Users shouldn't simply **consume** information. They should:

```
Discover → Understand → Explore → Interact → Question → Practice → Remember → Apply
```

## Product Definition

Rever combines multiple learning modes into a single platform:

```
Microlearning
     +
AI Tutor
     +
Visual Explanations
     +
Interactive Maps
     +
Knowledge Graphs
     +
Notes
     +
Flashcards
     +
Quizzes
     +
Audio
     +
Learning Paths
     +
Spaced Repetition
     +
Personalization
     =
PERSONAL LEARNING OS
```

## Guiding Principles

1. **Multi-profile by default** — One account, multiple independent learner profiles (adult + kids)
2. **Age-aware experiences** — Separate presentation engines for adults and children sharing the same platform
3. **Multiple representations** — Every concept has a READ, WATCH, EXPLORE, LISTEN, and INTERACT mode
4. **Source-grounded AI** — All AI responses are grounded in trusted sources
5. **Progress over consumption** — Reward understanding, not scrolling
6. **Knowledge as interface** — The user's knowledge graph is the primary navigation metaphor
7. **Start lean, scale smart** — v1 proves one loop exceptionally well; everything else attaches progressively
