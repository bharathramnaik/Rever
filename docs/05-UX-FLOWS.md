# UX Flows

## Onboarding Flow

```
Install → Welcome
           ↓
    Create Account (email / Google)
           ↓
    Create Profile (name, avatar)
           ↓
    Select Interests (topics)
           ↓
    Daily Goal (5/10/15 min)
           ↓
    First Concept (auto-play)
           ↓
    Home Screen
```

## Daily Journey Flow (Adult)

```
Home
  ↓
"Good morning, Bharath — Your 10-minute Journey"

[2 min] 🧠 Learn — How transformers understand language
[3 min] 🗺 Explore — Transformer visual map
[2 min] ❓ Quiz — Test yesterday's concepts
[2 min] 🔁 Remember — 3 concepts due for revision
[1 min] 💡 Discover — Something unexpected
```

## Concept Discovery Flow

```
Explore → Select Topic → See concept list
                              ↓
                        Tap concept
                              ↓
                    Concept Experience
                    ┌─────────────────┐
                    │  READ    WATCH  │
                    │  EXPLORE  LISTEN│
                    │  AI TUTOR  QUIZ │
                    │  SAVE     SHARE │
                    └─────────────────┘
                              ↓
                     Card view (swipeable)
                              ↓
                     AI Tutor (ask questions)
                              ↓
                     Quiz (test understanding)
```

## Kids Flow

```
Home → Today's Adventure
         ↓
    Story intro (animated)
         ↓
    Simple explanation
         ↓
    Interactive activity
         ↓
    Question
         ↓
    Reward (XP/Badge)
         ↓
    Next adventure
```

## Parent Dashboard Flow

```
Profile → Switch to Child → See dashboard
          ↓
    Weekly summary
    Strongest topics
    Need improvement
    Learning time
    Activity log
          ↓
    Settings (age level, time limit, topics, restrictions)
```
