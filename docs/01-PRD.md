# Product Requirements Document — v1.0

## Elevator Pitch

Rever is a personal learning OS that helps individuals and families turn what they want to learn into short, visual, interactive sessions — with an AI tutor, knowledge maps, quizzes, and spaced revision — all within a single app with separate profiles for adults and children.

## Target Users

| Persona | Description |
|---------|-------------|
| **Adult Learner** | Professional who wants to learn efficiently during commutes/breaks |
| **Student** | Teenager supplementing school with interactive study tools |
| **Parent** | Managing their own learning AND their children's learning journey |
| **Child (5-13)** | Learning through stories, animations, and gamified adventures |

## v1 Core Loop

```
Choose interests
       ↓
Discover concept
       ↓
Understand concept (card + visual)
       ↓
Explore visually (diagram/flowchart)
       ↓
Ask AI tutor
       ↓
Test understanding (quiz)
       ↓
Save to knowledge library
       ↓
Get reminded later (spaced repetition)
       ↓
Recommendation improves
```

## v1 Scope (Phase 1 — Core)

### Must Have
- Multi-profile accounts (up to 5 profiles per account)
- Adult mode (cards, feed, library, search)
- Topic-based browsing
- Learning cards with rich content
- Save/bookmark concepts
- Basic AI tutor (Q&A on concepts)
- Simple quiz (multiple choice)
- Daily learning journey
- Reading streak

### Won't Have (v1)
- Kids mode (Phase 6)
- Interactive flowcharts (Phase 4)
- Knowledge graph visualization (Phase 5)
- Learning Spaces (Phase 7)
- Audio narration (Phase 8)
- Advanced recommendations (Phase 9)

## Key Metrics (v1)

- DAU / MAU
- Concepts learned per session
- Quiz completion rate
- Streak retention (7-day, 30-day)
- Profile creation per account
- AI tutor query rate
